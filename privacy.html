Nenjah Bot Privacy Policy

Last updated: November 18, 2026

Nenjah Bot is a personal desktop tool run by DJ Nenjah on his own computer to manage his own YouTube channel. This policy explains what it does with data from Google and YouTube.

YouTube API Services

Nenjah Bot uses YouTube API Services. Please also read the YouTube Terms of Service and the Google Privacy Policy.

What data it accesses

  • The sign-in token for DJ Nenjah's own Google account, granted through Google's consent screen.
  • DJ Nenjah's own channel data: his videos, playlists, live broadcasts, thumbnails, and channel analytics.
  • Public live chat messages sent to DJ Nenjah's live streams (display name and message text), used only to answer chat commands and read approved messages aloud during the stream.

How it uses and stores data

  • Everything is processed on DJ Nenjah's own computer. The sign-in token is stored in a local file on that computer and is never sent anywhere except to Google.
  • Chat messages are used live and are not sold, shared, or used for advertising. Short local logs may be kept to fix problems and are deleted periodically.
  • No data is sold or shared with third parties. No data is used for advertising or to build profiles of viewers.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Cookies and devices

Nenjah Bot does not place cookies or tracking on viewers' devices.

Removing access and data

Access can be removed at any time at Google security settings. When access is removed, the local token is deleted, and stored API data is deleted within 30 days.
